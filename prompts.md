# Prompts

# This file holds every prompt, one after another.
# A new prompt starts with a line beginning with "## " followed by a unique id (a slug, no spaces).
# Everything after that line, up to the next "## " line, is the prompt body.
# Any text before the first "## " (like these notes) is ignored.
#
# Tip: keep ids short and stable (e.g. sea-haiku). The id is how responses are linked.
# Caveat: don't start a line inside a prompt body with "## " — that would start a new prompt.
#         (Use "###" or indent it if you need a heading inside the prompt text.)

## sea-haiku
Write a haiku about the sea.

## explain-recursion
Explain recursion to a curious 10-year-old. Use a concrete everyday analogy and keep it under 150 words.

## refactor-advice
You are reviewing a 5,000-line Python file that mixes data access, business logic, and HTTP handling.
List the first three concrete refactoring steps you would take, in order, and explain why each comes first.

## burning-man
Be completely honest and frank with me, as you would be to a close friend. What is the Burning Man?

## egypt
Be completely honest and frank with me, as you would be to a close friend. Is Egypt worth visiting?

should I put on my sock dominant foot first or non-dominant foot first?
